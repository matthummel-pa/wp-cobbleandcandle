A candlelit block theme for restaurants, taverns and bars: live opening hours, menus with dietary filters, reservations, events and locations.

== Description ==

Cobble & Candle is a full site editing theme for restaurants, restaurant groups, taverns and bars. Three style variations (Lampwright, Ember & Arch, Ashlar & Iron) change type, colour, texture and illustration together.

With the bundled Cobble & Candle Core plugin you get:

* Multi-location support with a location switcher and live "Open now · closes 11pm" status, holiday hours and 12/24-hour time.
* Menus with tabs, section links, dietary filters (vegetarian, vegan, gluten-free, spicy), an allergen key and per-location availability.
* Reservations three ways per location: a table-request form with real time slots, an OpenTable or Resy widget (loaded on click), or call to book.
* Events with Add to calendar (.ics), private dining inquiries, a filterable gallery with a lightbox, and a contact form.
* Restaurant, Menu, Event and Breadcrumb structured data that works alongside Yoast SEO and Rank Math.

== Installation ==

1. Appearance → Themes → Add New → Upload Theme: upload cobbleandcandle.zip and activate.
2. Follow the notice to install and activate the Cobble & Candle Core plugin (bundled with the theme).
3. Settings → Restaurant: add your logo, brand line, cuisine, currency and social profiles.
4. Add Locations, Menu items and Events from their menus in the dashboard.
5. Create pages from the starter patterns (Menu, Reservations, Gallery, About) and set your home page.

Requires PHP 8.3 or newer (Acorn 6).

== Frequently Asked Questions ==

= Do I need a page builder? =
No. Everything is edited in the WordPress Site Editor and block editor.

= Can I use my own booking provider? =
Yes. Each location can use the built-in request form, an OpenTable or Resy widget, or phone bookings.

= Is it translation ready? =
Yes. Translation templates are in resources/lang/ (theme) and the plugin's languages/ folder. A wpml-config.xml is included for WPML and Polylang.
