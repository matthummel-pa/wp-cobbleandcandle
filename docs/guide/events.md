# Events & private dining

## Events

**Events → Add event.** Set the start (and end) time, the house, a type (*Tasting*, *Live music*…), price, availability (“12 seats left”), a ticket or booking link, and optional courses. The excerpt and photo appear on cards.

- The Events page features the next event, then all upcoming events with **type filters**.
- Each event has **Add to calendar (.ics)** and appears in Google as an Event (date, place, price, availability).
- Past events drop off automatically.

## Private dining

The **Private dining** block (on the home page in the demo) shows your rooms for groups and an inquiry form: date, guest range, occasion, house, message. Inquiries go to the house’s email and are saved under **Messages**.
